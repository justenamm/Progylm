# Progylm Website

A static multi-page edtech website for **Progylm**.

## Brand

**Progylm**  
**Tagline:** Aspire - Condition - Transform

## Positioning

Progylm is a NEET-UG and CUET-UG oriented Biology and Physics learning brand. The redesigned website is inspired by the uploaded `preview 2.html` direction: technical preparation, exam conditioning, speed, precision, accuracy, and student-first trust.

## Tech Stack

- HTML
- CSS
- JavaScript
- No React
- No backend
- No paid APIs

- `contact.html`

- `README.md`

- `assets/icons/favicon.PNG`
