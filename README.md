# Progylm Website

Modern static edtech website for Progylm.

## Brand

**Progylm**  
**Tagline:** Aspire • Condition • Transform

## Focus

Progylm is a NEET-UG and CUET-UG oriented Biology and Physics learning brand that begins with free YouTube-first education.

## Tech Stack

- HTML
- CSS
- JavaScript
- No React
- No backend
- No paid APIs

## Pages

- `index.html`
- `about.html`
- `notes.html` / Learning page
- `contact.html`

## Upload

For Hostinger, upload all files and folders to `public_html`.

For GitHub, upload the project contents to a repository. The website can also be published with GitHub Pages.

## Link Editing

Replace these placeholder links in the HTML files:

- YouTube: `https://www.youtube.com/`
- Instagram: `https://www.instagram.com/`
- Telegram: `https://t.me/progylm`
- Email: `hello@progylm.com`

Keep the full `assets` folder uploaded so the Progylm logo appears correctly.
